# 🚀 Guia Rápido - Mapa Mental

### 1. Criar Seu Primeiro Mapa
```
1. Clique no nó azul central ("Projeto Principal")
2. Pressione ENTER ou clique em ➕
3. Digite o texto do novo nó
4. Pressione ENTER para confirmar
5. Repita para adicionar mais nós
```

### 2. Organizar Visualmente
```
Arraste os nós para reorganizá-los
Use a roda do mouse para fazer zoom
Clique em 🎯 para centralizar
```

---

## 🎨 Personalizando Nós

### Editar um Nó
```
1. Clique no nó para selecioná-lo
2. O painel lateral aparecerá
3. Modifique:
   - Texto
   - Ícone (30+ opções)
   - Forma (5 tipos)
   - Prioridade (Alta/Média/Baixa)
   - Cores
   - Notas
```

### Exemplo: Nó com Prioridade Alta
```
1. Selecione o nó
2. Escolha "🔴 Alta" em Prioridade
3. Clique em 💾 Salvar
→ Um círculo vermelho aparecerá no nó
```

## 💾 Salvando Seu Trabalho

### Salvar em JSON (Recomendado)
```
Menu Arquivo → Salvar
→ Baixa arquivo com extensão .json
→ Pode ser aberto novamente no aplicativo
```

### Exportar para Imagem
```
Menu Arquivo → Exportar
Escolha: PNG (melhor qualidade) ou JPG (menor tamanho)
→ Pronto para usar em documentos
```

### Exportar para HTML
```
Menu Arquivo → Exportar
Escolha: HTML
→ Arquivo interativo que pode ser aberto em qualquer navegador
→ Inclui tooltip, zoom e expandir/recolher
```

### Exportar para Texto
```
Menu Arquivo → Exportar
Escolha: TXT
→ Formato indentado, fácil de ler
→ Útil para documentação
```

## 🔍 Funcionalidades Principais

### Expandir/Recolher Nós
```
Clique no ➖ ou ➕ ao lado do nó
→ Recolhe/expande todos os filhos
→ Útil para focar em uma área específica
```

### Desfazer/Refazer
```
CTRL+Z → Desfazer última ação
CTRL+Y → Refazer ação desfeita
→ Histórico de 50 ações
```

### Auto Layout
```
Clique em 📊 Auto Layout
→ Reorganiza automaticamente todos os nós
→ Útil quando o mapa fica desorganizado
```

## ⌨️ Atalhos Essenciais

| Atalho | O que faz |
|--------|-----------|
| `DELETE` | Excluir nó |
| `CTRL+Z` | Desfazer |
| `CTRL+Y` | Refazer |
| `CTRL+S` | Salvar |
| `+` / `-` | Zoom in/out |
| `ESC` | Cancelar/Fechar painel |


## ❓ Dúvidas Frequentes

### P: Como importar um arquivo TXT?
```
R: Menu Arquivo → Importar TXT
   Selecione arquivo com estrutura indentada
   O mapa será criado automaticamente
```

### P: Posso editar o mapa exportado em HTML?
```
R: O HTML exportado é interativo (zoom, tooltip, expandir/recolher)
   mas não permite adicionar/editar nós
   Para editar, abra o arquivo JSON no aplicativo
```

### P: Quantos nós posso ter?
```
R: Até ~1000 nós (recomendado)
   Acima disso, o desempenho pode diminuir
```

### P: Os dados são salvos automaticamente?
```
R: Não. Use CTRL+S ou Menu → Salvar para salvar
   O aplicativo não usa internet, tudo é local
```

### P: Posso usar em dispositivos móveis?
```
R: Sim, mas a experiência é melhor em desktop
   Tela pequena limita a visualização do mapa
```

## 🆘 Solução de Problemas

### Mapa desapareceu
```
1. Verifique se o navegador não foi atualizado
2. Abra o arquivo JSON salvo anteriormente
3. Se nada funcionar, tente outro navegador
```

### Zoom não funciona
```
1. Clique no canvas primeiro para focar
2. Use os botões 🔍- e 🔍+ se a roda não funcionar
```

### Nós sobrepostos
```
1. Clique em 📊 Auto Layout para reorganizar
2. Ou arraste manualmente para separar
```

### Arquivo muito grande
```
1. Exporte em JPG em vez de PNG (menor tamanho)
2. Ou exporte em TXT para documentação
```

## 💡 Dicas Profissionais

### Organizar Grandes Mapas
```
1. Use cores para categorias
2. Use ícones para tipos de tarefas
3. Use prioridades para destaque
4. Recolha ramos menos importantes
5. Use busca para encontrar rapidamente
```

### Apresentar o Mapa
```
1. Exporte em HTML para apresentação interativa
2. Ou exporte em PNG/JPG para slides
3. Use o zoom para focar em áreas específicas
4. Recolha nós para revelar gradualmente
```

### Colaboração
```
1. Salve o arquivo JSON
2. Compartilhe com colegas
3. Cada um pode abrir e editar
4. Mescle as versões manualmente
```
